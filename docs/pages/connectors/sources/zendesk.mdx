Connector ID `zendesk`

The Zendesk Support source reads users, tickets, organizations, groups, ticket fields, brands, custom roles, satisfaction ratings, tags, and ticket comments from the Zendesk Support REST API. It uses an [HTTP manifest](/pages/connectors/building-a-connector/http-manifests). This connector is in preview. It targets API version `v2`.

## Configuration

| Field | Scope | Default | Description |
|---|---|---|---|
| `subdomain` | Connection | | Required. Zendesk subdomain, such as `mycompany` for `mycompany.zendesk.com`. |
| `auth_method` | Connection | `api_token` | Optional. Choose `api_token` for Basic Auth or `oauth_access_token` for an OAuth Bearer token. |
| `email` | Connection | | Required when using `api_token`. Email address of an admin or agent account. |
| `api_token` | Connection | | Required when using `api_token`. Secret. API token generated in Zendesk Admin Center. |
| `access_token` | Connection | | Required when using `oauth_access_token`. Secret. OAuth access token generated via a Zendesk OAuth client. |

Connection testing calls `GET /api/v2/users.json?page[size]=100`. Requests target `https://{subdomain}.zendesk.com`.

## Resources

All resources except `ticket_comments` are selected by default. Selecting `ticket_comments` fans out across parent tickets.

## Modes

All resources perform full reads. Use **full upsert** to refresh rows or **full replace** to remove rows that are no longer present in Zendesk.

## Behavior

- **Auth**. Every request sends either HTTP Basic Authentication with `{email}/token` and `api_token`, or a Bearer token when `auth_method` is `oauth_access_token`.
- **Pagination**. Endpoints use cursor-based pagination with `page[size]=100`, walking `page[after]` from `meta.after_cursor` until `meta.has_more` is false.
- **Rate limiting**. Standard Zendesk Support API limits allow up to 700 requests per minute. The connector paces requests at 10 requests per second with burst capacity of 10.

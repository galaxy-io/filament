Filament ships source connectors for databases, manifest-driven SaaS apps
sharing one HTTP implementation, and a synthetic generator for testing.

## Databases

| Source | Package | Notes |
|---|---|---|
| [PostgreSQL](/pages/connectors/sources/postgres) | `connectors/postgres/source` | Adaptive read-mode routing (keyset, bitmap, ctid); full + incremental + CDC |
| [MySQL](/pages/connectors/sources/mysql) | `connectors/mysql/source` | Keyset reads plus GTID-based CDC |

## SaaS Apps

All ten run on the same [HTTP](/pages/connectors/sources/http) connector,
configured by a declarative manifest rather than by their own Go package:

| Source | Manifest | Notes |
|---|---|---|
| [Attio](/pages/connectors/sources/attio) | `attio.yaml` | 23 resources — the deepest parent/child nesting of the ten |
| [Chargebee](/pages/connectors/sources/chargebee) | `chargebee.yaml` | 11 resources across subscription billing and the product catalog; site-scoped host, incremental on `updated_at` throughout |
| [GitHub](/pages/connectors/sources/github) | `github.yaml` | Repositories, issues, pull requests for one organization |
| [Linear](/pages/connectors/sources/linear) | `linear.yaml` | The one GraphQL manifest — everything else is REST |
| [Notion](/pages/connectors/sources/notion) | `notion.yaml` | Databases, pages, blocks |
| [PostHog](/pages/connectors/sources/posthog) | `posthog.yaml` | 11 resources across people, events, flags, experiments, and replay; the one manifest with a config-selected host |
| [Resend](/pages/connectors/sources/resend) | `resend.yaml` | 23 resources across sent and inbound email, contacts, segments, and webhooks |
| [Slack](/pages/connectors/sources/slack) | `slack.yaml` | Incremental message sync on the `ts` cursor |
| [Square](/pages/connectors/sources/square) | `square.yaml` | Payments, refunds, orders, customers, and catalog across seller locations |
| [Stripe](/pages/connectors/sources/stripe) | `stripe.yaml` | 21 resources across payments, billing, and the balance ledger; incremental on `created` for the ten ledger streams |

## Custom & Testing

| Source | Package | Notes |
|---|---|---|
| [HTTP](/pages/connectors/sources/http) | `connectors/http` | The manifest-driven mechanism the ten SaaS sources above run on; new APIs are onboarded declaratively |
| [Sample](/pages/connectors/sources/sample) | `connectors/sample` | Synthetic data, for testing pipelines without a real upstream |

Every source implements the base `Source` contract; several add optional
capabilities like resumability or CDC. See [Optional
interfaces](/pages/connectors/building-a-connector/optional-interfaces) for the
full list.

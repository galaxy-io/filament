The stable Sample source generates predictable rows without an external system.
Use it with the [stdout](/pages/connectors/sinks/standard-output) sink for demos,
tests, or checking end-to-end pipeline wiring.

## Configuration

| Field | Scope | Default | Description |
|---|---|---|---|
| `rows` | Pipeline | `3` | Rows to emit per resource. |

## Resources

Resource discovery lists `users` and `orders`, both with primary key `id`. A
run emits whichever resources it requests. With no resource selection, the
source emits one `items` resource.

Each record's id is its index, with data:

```json
{"resource": "users", "i": 0}
```

`rows` values of zero or less still produce one row per resource. Discovery's
estimated row count remains 3 regardless of this setting.

## Modes

Full only, with `full_replace` as the only write policy.

The Sample source generates synthetic data for exercising a pipeline (or
the engine itself) with no upstream system configured. It is the
zero-dependency reference source, the counterpart to the
[stdout](/pages/connectors/sinks/standard-output) sink for end-to-end wiring, demos,
and tests. The connector is stable.

## Configuration

| Field | Scope | Default | Description |
|---|---|---|---|
| `rows` | Pipeline | `3` | Rows to emit per resource. |

## Resources

Discover returns two fixed selectable resources, `users` and `orders`, each
with primary key `id`. Extract emits rows for whatever resources the run
requests. When none are requested it emits a single `items` resource.

Each record's id is its index, with data:

```json
{"resource": "users", "i": 0}
```

Setting `rows` to zero or below still emits one row per resource (Discover
continues to estimate 3).

## Modes

Full only, with `full_replace` as the only write policy.

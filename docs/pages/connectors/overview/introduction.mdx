A connector is a source, a sink, or both. Sources read data from an upstream
system, and sinks write it to a destination. Some connectors ship both as
separate packages (`connectors/postgres/source`, `connectors/postgres/sink`).

When embedding Filament, include a connector with a blank import:

```go
_ "github.com/galaxy-io/filament/connectors/postgres"
```

Each package registers a fresh connector instance for every run. Its spec
provides the name, configuration fields, capabilities, and maturity shown by
the API and web app.

## Maturity levels

Every connector is registered with one of three maturity levels.

| Level | Meaning |
|---|---|
| `alpha` | Documentation-derived, not yet tested end to end |
| `beta` | Runs end to end. Not verified for every supported object or environment |
| `stable` | Fully production-ready across its supported objects |

Most SaaS sources are YAML manifests interpreted by one generic
[HTTP connector](/pages/connectors/building-a-connector/http-manifests).
Adding another SaaS API is
usually a new manifest, not a new connector. The manifest format is
documented in
[HTTP manifests](/pages/connectors/building-a-connector/http-manifests).

## Sinks

| Sink | Maturity | Writes |
|---|---|---|
| [PostgreSQL](/pages/connectors/sinks/postgres) | beta | Typed tables. Replace, append, upsert, and CDC merge |
| [MySQL](/pages/connectors/sinks/mysql) | alpha | Typed tables. Same write policies as the PostgreSQL sink |
| [NATS JetStream](/pages/connectors/sinks/nats) | alpha | Acknowledged JSON messages; bounded and continuous append |
| [ClickHouse](/pages/connectors/sinks/clickhouse) | alpha | MergeTree tables. Atomic replace via staging, no CDC |
| [MotherDuck](/pages/connectors/sinks/motherduck) | alpha | Cloud DuckDB tables through the bulk appender. Worker `-libc` image only |
| [Snowflake](/pages/connectors/sinks/snowflake) | alpha | Typed tables loaded from staged Parquet batches |
| [Amazon Redshift](/pages/connectors/sinks/redshift) | alpha | Typed tables loaded from S3-staged Parquet manifests |
| [Meilisearch](/pages/connectors/sinks/meilisearch) | alpha | Search documents, one index per resource. Add or replace by primary key |
| [Iceberg](/pages/connectors/sinks/iceberg) | alpha | Parquet tables; data commits per resource at run end |
| [Amazon S3](/pages/connectors/sinks/aws-s3) | alpha | NDJSON objects, one per resource per run |
| [stdout](/pages/connectors/sinks/standard-output) | stable | NDJSON to standard output, the reference sink |

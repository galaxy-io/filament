A connector is a source, a sink, or both. Sources read data from an upstream
system, and sinks write it to a destination. Some connectors ship both as
separate packages (`connectors/postgres/source`, `connectors/postgres/sink`).

When embedding Filament, include a connector with a blank import:

```go
_ "github.com/galaxy-io/filament/connectors/postgres"
```

Each package registers a fresh connector instance for every run. Its spec
provides the name, configuration fields, capabilities, and preview status shown by
the API and web app.

## Preview connectors

Connectors marked `is_preview` have not been confirmed stable across their
supported objects and environments. The API and web app show this flag.
New connectors start in preview. Clear the flag after live validation confirms
the supported behavior.

[HTTP connector](/pages/connectors/building-a-connector/http-manifests).

usually a new manifest, not a new connector. The manifest format is
documented in
[HTTP manifests](/pages/connectors/building-a-connector/http-manifests).

## Sinks

| Sink | ID | Preview | Writes |
|---|---|---|---|
| [PostgreSQL](/pages/connectors/sinks/postgres) | `postgres` | No | Typed tables. Replace, append, upsert, and CDC merge |
| [MySQL](/pages/connectors/sinks/mysql) | `mysql` | No | Typed tables. Same write policies as the PostgreSQL sink |
| [NATS JetStream](/pages/connectors/sinks/nats) | `nats` | No | Acknowledged JSON messages; bounded and continuous append |
| [Kafka](/pages/connectors/sinks/kafka) | `kafka` | No | Acknowledged JSON or raw messages. Bounded and continuous append |
| [ClickHouse](/pages/connectors/sinks/clickhouse) | `clickhouse` | No | MergeTree tables. Atomic replace via staging, no CDC |
| [Databricks Zerobus](/pages/connectors/sinks/databricks-zerobus) | `databrickszerobus` | Yes | Delta tables through the Zerobus Ingest API. Append only, CDC as history rows. Worker `-libc` image only |
| [MotherDuck](/pages/connectors/sinks/motherduck) | `motherduck` | Yes | Cloud DuckDB tables through the bulk appender. Worker `-libc` image only |
| [Snowflake](/pages/connectors/sinks/snowflake) | `snowflake` | Yes | Typed tables loaded from staged Parquet batches |
| [Amazon Redshift](/pages/connectors/sinks/redshift) | `redshift` | Yes | Typed tables loaded from S3-staged Parquet manifests |
| [Meilisearch](/pages/connectors/sinks/meilisearch) | `meilisearch` | Yes | Search documents, one index per resource. Add or replace by primary key |
| [Iceberg](/pages/connectors/sinks/iceberg) | `iceberg` | No | Parquet tables; data commits per resource at run end |
| [Google BigQuery](/pages/connectors/sinks/bigquery) | `bigquery` | No | Typed tables through the Storage Write API. Snapshot, incremental, and CDC |
| [Amazon S3](/pages/connectors/sinks/aws-s3) | `s3` | No | NDJSON objects, one per resource per run |
| [Google Cloud Storage](/pages/connectors/sinks/gcs) | `gcs` | Yes | NDJSON, JSON, or Parquet objects, one per resource per run |
| [stdout](/pages/connectors/sinks/standard-output) | `stdout` | No | NDJSON to standard output, the reference sink |

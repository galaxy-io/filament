Defined in `api/ingestion/v1/connectors.proto`. This is how the UI and other
clients discover the registered connectors without maintaining a hardcoded
list.

## RPCs

| RPC | Purpose |
|---|---|
| `ListConnectors` | Catalog registered source and sink connectors and their config schemas |
| `ValidateConfig` | Validate a candidate config against a connector's schema |
| `DiscoverResources` | Browse a source's available resources |
| `GetResourceColumns` | Load column metadata for selected resources |

Before anything can move, Filament needs to know how to reach your systems.
That happens on the Sources and Sinks pages. Sources are the places data
comes from, like a Postgres database or a SaaS tool. Sinks are the places it
lands, like a warehouse or another database.

Each page shows a catalog of everything Filament can talk to, with a badge
for how battle-tested each one is.

## Creating a connection

Pick something from the catalog and a form opens asking only for what that
system needs. Usually an address and credentials, sometimes a couple of
options. Fields appear and disappear based on your choices, so you never see
settings that don't apply.

Filament checks the details before saving, so a typo in a hostname or
password surfaces right away instead of failing a run later. Credentials are
stored encrypted and never shown again, not even to you. Edit a connection
later and everything is there except the secrets, which stay put unless you
type new ones.

Once saved, a connection is reusable. Any number of pipelines can draw from
the same one.
